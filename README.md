# rushello

[![progress-banner](https://backend.codecrafters.io/progress/shell/fa1a013d-0d2d-4c3b-82a1-e63caac50ecf)](https://app.codecrafters.io/users/lungarella-raffaele?r=2qF)

A simple shell application written in Rust as part of the [CodeCrafters "Build Your Own Shell" challenge](https://app.codecrafters.io/courses/shell/overview).

## About the name

**rushello** combines _Rust_ and _shell_. The result sounds like _ruscello_, the Italian word for “stream”—hence **rushello**.
